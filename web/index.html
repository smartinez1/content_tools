How to name the exports

In Oto: Export → Length → Custom (one range at a time, in order) and Fade → No fade. Export every range under the same name, e.g. espacio tiempo (2am) - Compose. Oto adds _2, _3… when the name is taken, and that suffix is what groups the pieces and sets their order (_2 before _10).

Ranges must be back to back (no gap, no overlap) and use the same size and frame rate. Files named … 1.mp4, … 2.mp4 (a space and a number, no underscore) are not grouped automatically: rename them to the pattern above.
